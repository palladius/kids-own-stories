# Workflow Guidelines — Kids' Own Stories

- **Git Worktrees + HITL (`conductor-worktree-hitl`)**: Feature tracks run in isolated Git worktrees (`.worktrees/<track-or-issue>`) with GitHub Issues and visual/audio review in `creative-draft.html`.
- **Versioning**: Always update `VERSION` and `CHANGELOG.md` on every feature release (`git-coding`).
- **Deterministic Assets**: Every story must be registered in `stories.yaml` with complete `checklist` verification.
